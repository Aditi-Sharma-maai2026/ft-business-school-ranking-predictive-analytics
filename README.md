# ft-business-school-ranking-predictive-analytics
MSc thesis: reverse-engineered the FT European Business Schools ranking formula in Python, confirming an undocumented preprocessing step absent from prior literature. Trained 10 ML models on 1,090 school-year observations (100+ schools). Programme participation (r=−0.954) outweighs salary (r=−0.014) as the dominant rank driver.
